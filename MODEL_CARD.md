# ChurnIQ-ML Model Card

## Intended use
Educational and portfolio demonstration of an end-to-end customer churn classification workflow.

## Data
The project uses the publicly documented IBM Telco Customer Churn sample dataset. The dataset represents a fictional telecommunications business and should not be interpreted as evidence about any real company's customers.

## Method
The training pipeline performs a stratified holdout split, leakage-safe preprocessing with scikit-learn pipelines, cross-validation, and comparison of Logistic Regression and Random Forest classifiers.

## Metrics
Performance metrics must be generated by the training run and recorded in the experiment output. No metrics are hard-coded in this document.

## Limitations
The dataset is a sample dataset and may not represent real production populations. Model predictions are probabilistic and should not be treated as definitive decisions about individual customers. Before operational use, the pipeline would require representative data, monitoring, calibration, fairness analysis, privacy review, and business validation.
